# Into-The-Abyss
The purpose of this project is to study how to design and develop games and apply them to develop practical works by bringing one of the most interesting and popular game genres, the role-playing game (RPG), where players take on the role of characters in the game. And also choose to use 2D-pixel art images. In the development of the game, Unity was used in combination with the C# language, and some knowledge, experience, and theories such as breadth-first search (BFS), A-star algorithm, and technology such as Amazon Web Services (AWS) were applied to this development.

As a result of this project, it was possible to develop a game that meets the objectives and scope of this project. The resulting game can be used and can be developed further. Additional parts can be added as appropriate.
